# Recipe Manager

A bilingual recipe website built with WordPress.

## Overview

Recipe Manager is a portfolio project showcasing custom WordPress
development, structured recipe management, and interactive frontend
features.

## Features

- Custom WordPress theme
- Custom Recipe Post Type
- Advanced Custom Fields integration
- English and Spanish support
- Recipe search and filtering
- Dynamic serving adjustments
- Ingredient measurement conversions
- Print-friendly recipes
- Responsive design

## Tech Stack

- WordPress
- PHP
- JavaScript
- CSS
- Advanced Custom Fields
- Elementor
- DevKinsta (local development)

## Project Structure

- `themes/recipe-manager/` - Custom WordPress theme
- `plugins/recipe-manager-core/` - Custom WordPress functionality

## Development

Local development is managed using DevKinsta.

The WordPress core, database, uploaded media, and third-party
plugins are not included in this repository.
